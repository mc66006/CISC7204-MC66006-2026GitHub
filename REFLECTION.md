# Submission reflection

This portfolio demonstrates practical skills in data cleaning, exploratory analysis, visualization, reproducible scripting, and responsible interpretation. I translated a course-provided Seattle apartment-rent CSV into a clear research question about rent levels, mixed-income housing, and change over time. The project validates columns and missing values, creates four readable figures, and records a repeatable environment in `requirements.txt`. I also retained the original notebook so the final script can be compared with the exploratory work.

The main finding is descriptive: rent differs across years and communities, and mixed-income apartment counts show an association with rent levels. The relationship cannot be interpreted as a causal effect because the data are aggregated and omit important factors such as location, unit mix, income, vacancy, and inflation. My next improvement would be a time-aware evaluation and a better documented, licensed source for the dataset. I would also test a model with tract-level grouping and inflation-adjusted rent before making stronger comparisons. Peer feedback led me to add the labelled figures, an explicit limitation section, and a reproducible command so another student can run the analysis.
