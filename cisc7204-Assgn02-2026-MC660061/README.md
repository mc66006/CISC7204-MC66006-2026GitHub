# Assignment 02 archive

This directory contains the Module 01–05 coursework archive and the Pair 14 college-tuition proposal under [`personalproposal/`](personalproposal/).

The Module folders are retained as course exercises. They do not each require a separate portfolio website. The portfolio website and its reproducible final project are maintained at the repository root and in the separate GitHub Pages repository.

The proposal folder contains the source proposal, notebook, raw College Scorecard extract, and cleaned analysis data. See [`personalproposal/README.md`](personalproposal/README.md) for the research question, provenance, and reproduction instructions.

The executed results and limitations are in [`personalproposal/RESULTS.md`](personalproposal/RESULTS.md), with the standalone reproduction script at [`personalproposal/analyze_college_scorecard.py`](personalproposal/analyze_college_scorecard.py).
