# CISC7204 Bonus Assignment 3

This folder contains the Bonus Assignment 3 practice notebooks for Topics 01–05. Each topic keeps its notebook together with the small dataset files and screenshots used to document the exercises.

## Topics

- **Topic 01:** series operations, Boolean filtering, strings, and price cleaning.
- **Topic 02:** item revenue DataFrames, MPG filtering, and weighted economy.
- **Topic 03:** penguin missing-value analysis, imputation, and group counts.
- **Topic 04:** crosstabs, pivot tables, and grouped aggregation.
- **Topic 05:** concatenation, joins, JSON/CSV/Excel workflows, and spreadsheet handling.

The notebooks are educational practice materials. Run them from their topic folder so relative dataset paths resolve correctly. The repository contains no passwords, API keys, or private student records.
